课程设计说明

关于这个项目

一个面向非粮生物柴油植物的知识查找与匹配网站。

项目背景

本项目依据《中国非粮生物柴油植物》课程设计资料，将苏铁科、银杏科、松科、杉科等植物的 中文名、英文名、拉丁学名、别名、科、属、形态特征、分布、栽培、用途、图片以及含油率和 脂肪酸化学组分整理为结构化数据，提供组合查询、结果字段选择、详情查看、收藏和后台维护功能。

主要功能

组合查询

关键词、科、属、含油率范围、是否有含油数据、排序方式自由组合。

结果字段选择

中文名、英文名、拉丁学名、别名、科属、特征、分布、栽培、用途、含油率任选。

用户与角色

游客查询；注册用户收藏；管理员维护植物、含油率记录和用户。

网络扩展知识

详情页提供百度百科、GBIF、POWO、iPlant 等外部检索入口。

技术实现

后端框架Spring Boot 3.5、Spring MVC
页面模板Thymeleaf（服务端渲染，前后端不分离）
数据访问JdbcTemplate + 原生 SQL，对应 JDBC 技术点
数据库MySQL 8 / MariaDB，包含用户、作物、含油率、收藏等表
登录与权限HttpSession + 自定义 Filter + BCrypt 密码哈希
前端HTML5、CSS3、JavaScript、Bootstrap 5
部署Maven 打包为可执行 jar，内置 Tomcat，`java -jar` 启动

数据来源

《中国非粮生物柴油植物》课程设计资料（扫描版），整理范围为该书第 11–29 页。

部分扫描页存在缺字、空白或“微量”等原始标注，系统按可识别内容录入，并在备注列保留说明。

评分点对应

  • 前端页面：Bootstrap 5 + 自定义 CSS + 响应式布局。
  • 表单验证：HTML5、JavaScript 与 Jakarta Validation 服务端校验。
  • Java Web 业务：Spring MVC、JavaBean、Filter、JdbcTemplate。
  • 特定功能：组合查询、字段选择、分页、详情、收藏、后台 CRUD。
  • 部署与自学：可执行 jar、MySQL、Thymeleaf、Spring Boot。
